# 盈利质量检查清单

对每一项给出**结论 + 依据数字 + cid**；数据不足时明确写"数据不足，无法判断"。

## 核查项（≥6 项，逐项过）

1. **经营现金流 / 净利润**
   - 比值长期 < 1 → 利润未转化为现金，**最重要的一条**。
   - 单年 < 1 可解释（扩张期备货），连续 3 年 < 1 需警惕。

2. **应收账款增速 vs 营业收入增速**
   - 应收增速持续快于营收 → 可能放宽信用政策换收入，回款质量下降。
   - 关注应收占营收比重的趋势。

3. **存货周转天数**
   - 持续上升 → 产品滞销或备货过度，可能面临减值。
   - 需结合行业景气度判断（旺季备货属正常）。

4. **非经常性损益占净利润比重**
   - 占比高 → 利润来自变卖资产/政府补助/投资收益，**不可持续**。
   - 用扣非净利润复算增长，看是否仍有增长。

5. **毛利率异常波动**
   - 毛利率显著高于同业且无品牌/技术解释 → 需核实收入确认口径。
   - 毛利率突然大幅提升且无提价/降本说明 → 存疑。

6. **其他应收款 / 关联交易**
   - 其他应收款占比高 → 可能存在资金占用（大股东占款）。
   - 关联交易收入占比高 → 收入独立性存疑，查 `get_announcements` 的关联交易公告。

7. **费用率与利润增速的背离**（可选第 7 项）
   - 利润增速远高于营收增速，但费用率未下降 → 增长来源需核实（是否依赖非经营性收益）。

## 总评口径

| 结论 | 判定 |
|---|---|
| 健康 | 全部核查项无明显异常，经营现金流/净利润 ≥ 1 |
| 需关注 | 有 1–2 项偏离，但可用业务原因解释 |
| 存疑 | ≥3 项异常，或经营现金流/净利润连续多年 < 1 |

## 纪律

- 每项结论必须带 citation；不得用"一般来说"替代具体数字。
- 发现异常时**只陈述事实与可能解释**，不指控造假（数据不足以支撑定性）。
- 数据缺失时如实说明缺哪张表、哪个期间。
