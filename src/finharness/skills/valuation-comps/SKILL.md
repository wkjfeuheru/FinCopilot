# 可比公司相对估值

## 可比标的选取标准

按优先级由强到弱：

1. **同一行业**（必需）——业务可比是第一前提。
2. **相近规模**（市值量级接近，避免龙头与小市值直接比）。
3. **相近成长性**（营收/利润增速差不超过一个档位）。
4. **相近盈利模式**（to C / to B、直销 / 经销、重资产 / 轻资产）。
5. **相近资本结构**（负债率差异大时，PB 比 PE 更可比）。

- 可比组一般 5–10 家；少于 3 家时结论可信度应下调并说明。
- 用 `get_peers(symbol)` 取得系统给出的同业估值对比，再按其结果筛选。

## PE / PB 修正因子

原始倍数差异大时，需向"可比口径"修正后再比：

| 指标 | 修正方向 | 说明 |
|---|---|---|
| PE | 按成长性修正（PEG） | 高增速可承受高 PE；PEG = PE / 利润增速，接近 1 为常见参考 |
| PE | 剔除一次性损益 | 用扣非净利润，避免非经常损益压低/抬高 PE |
| PB | 按 ROE 修正 | 高 ROE 支撑高 PB；ROE 低于资金成本时 PB 应低于 1 |
| PS | 按净利率修正 | 净利率差异大时 PS 不可直接比 |

## 使用步骤

1. 取可比组估值数据（`get_peers`）。
2. 剔除异常值：亏损公司（PE 无意义）、ST、极端倍数。
3. 计算可比组中位数（**用中位数而非均值**，避免被极端值带偏）。
4. 定位目标标的的相对分位，结合自身成长性与 ROE 判断溢价/折价是否合理。
5. 输出对比表 `{table:comps}`，含每家标的的关键指标与分位说明。

## 陷阱

- **亏损或微利公司的 PE 为负或极高**，此时 PE 不可用，应改用 PB 或 PS 并说明。
- **周期股在高盈利时 PE 最低**（盈利高点），此时低 PE 是卖出信号而非便宜——需结合周期位置判断。
- **跨行业比倍数无意义**，即使数字看起来接近。
- 结论只说"相对贵/便宜"，**不给买卖建议**；数据须带 citation。
