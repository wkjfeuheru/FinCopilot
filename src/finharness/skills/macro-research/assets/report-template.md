# 宏观研究报告模板

> 用途：用户明确要求宏观研报成稿时使用。前提同上：素材先齐、cids 先有。

## 章节结构

1. **核心观点**（3–5 条）
   - 周期定位、政策组合、主要传导判断，**每条带 {cite:cid}**。
2. **经济周期定位**
   - 四阶段判断 + 至少两个指标的交叉印证（各指标标注所属月份与来源）；
   - 美林时钟式资产方向参考（表述为风格传导，非择时信号）。
   - **建议配图**：PMI/GDP 等**单个**指标的多年趋势 → 折线；不同量纲指标不叠加。
3. **政策环境评估**
   - 货币政策：立场（宽松/中性/紧缩）+ 具体操作（降准幅度/利率变化）+ 流动性数据验证。
   - 财政政策：力度（赤字率/专项债增量口径）+ 投向结构 → 受益方向。
   - 监管环境：重点领域 + 对行业格局的影响层次（情绪/业务/格局）。
   - **建议配图**：社融或 LPR 等单个指标趋势 → 折线（图注写明指标与期间）。
4. **外部环境**
   - 主导外部变量识别（美联储/汇率/地缘/大宗）+ 传导链条；次要变量简述。
5. **资产影响分析**
   - 按"周期定位 + 政策组合 → 风格/行业方向"推导传导链；
   - 每条传导写明机制与时滞，区分历史相关性与本次判断依据。
6. **风险提示**（≥5 条，每条 = 风险 + 触发条件 + 观测指标）
   - 候选：政策不及预期、外部变量突变、数据口径修正、传导时滞误判。
7. **附录**
   - 数据来源由管道自动生成，不手写。

## 写作纪律（成稿必守）

- 每个宏观数字标注**发布机构 + 所属期间**（"2026 年 8 月 CPI，国家统计局"）。
- 周期定位是概率性判断："更接近 X 阶段，依据是…"，附转向观察条件。
- 资产影响写成条件判断与传导链，**不下买卖建议、不给目标价**。
- 政策解读以原文为准并标注来源；征求意见稿/未落地政策标注状态。
- 数字带 {cite:cid}；正文不出现工具名与取数过程。
- 配图按内容判断：单指标趋势→折线，图注写明指标名、发布机构与期间；
  不同量纲指标不叠加，需对比时用表格或分图。
