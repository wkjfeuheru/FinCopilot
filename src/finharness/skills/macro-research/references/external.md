# 外部环境影响

> 工具联动：`get_macro_indicators`（汇率/美债）、`get_kline`（A 股对冲验证，可选）。
> 外部公开信息（美联储、地缘等）用 `web_search` 检索并标注来源与日期。

## 一、关键外部变量

- **美联储政策**：加息/降息周期、资产负债表缩表。
- **汇率波动**：人民币汇率走势、资本流动。
- **地缘政治**：贸易摩擦、制裁、供应链安全。
- **大宗商品**：原油、铁矿石、农产品价格。

## 二、传导机制（A 股视角）

- 美联储加息 → 全球流动性收紧 → 新兴市场资本外流 → 估值承压（成长股尤甚）。
- 大宗商品涨价 → 输入性通胀 → PPI 上行 → 中游企业利润承压。
- 地缘冲突 → 供应链中断 → 特定行业供需失衡。
- 人民币贬值 → 出口企业竞争力提升 / 进口成本上升（分行业双向影响）。

## 三、判读纪律

- 外部变量对 A 股的传导是**间接且时变的**：给出传导链条与历史相关性，
  不写成确定性因果（"美联储加息=A股必跌"是错误表述）。
- 相关性表述注明观察区间；政策与数据标注日期与来源。
- 多个外部变量叠加时，区分主导变量与次要变量，不平行罗列。
- 跨资产结论（股债汇商）区分数据可得性：A 股以内的用取数印证，以外的
  （美股/美债）用公开来源并标注。
