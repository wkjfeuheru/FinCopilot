# 经济周期判断

> 工具联动：`get_macro_indicators`（GDP/CPI/PMI 等指标）、`get_kline`（指数走势与
> 周期阶段的市场印证）、`make_chart`（单指标历史趋势折线；不同量纲指标不叠加）。

## 一、四阶段识别

| 阶段 | 特征 |
|---|---|
| 复苏期 | GDP 增速回升，PMI>50，通胀温和，企业盈利改善 |
| 繁荣期 | GDP 高增长，PMI 高位，通胀抬头，产能利用率提升 |
| 滞胀期 | GDP 增速放缓，通胀高企，货币政策收紧，企业利润承压 |
| 衰退期 | GDP 负增长，PMI<50，通胀回落，去库存压力加大 |

## 二、判断指标

GDP 增速及趋势、PMI、工业增加值增速、固定资产投资增速、社会消费品零售总额增速。

## 三、美林时钟式的资产映射（参考框架）

| 阶段 | 占优资产方向（传导逻辑） |
|---|---|
| 复苏 | 股票（盈利改善先于估值） |
| 繁荣 | 商品（需求过热推升价格） |
| 滞胀 | 现金/短债（股债双杀环境） |
| 衰退 | 债券（宽松预期升温） |

## 四、判读纪律

- 阶段判断**至少两个指标交叉印证**（如 GDP 增速 + PMI + CPI），单指标不定位周期。
- 每个指标标注**所属月份**与来源；数据滞后性要说明（GDP 季度、PMI 月度）。
- 周期定位是概率性判断：写"更接近 X 阶段，依据是…"，并给出转向的观察条件
  （"若 PMI 连续两月回落至 50 下方，则…"）。
- 资产映射是**风格/方向性传导**，不是择时信号，更不是买卖建议。

**配图**（增强解读，非必需）：PMI 或 GDP 等**单个**指标的多年趋势 → `make_chart(type="line",
cids=[宏观cid], y="value")`，图注写明指标名、发布机构与期间。**不同量纲的指标不要画在同一张图**
（PMI 指数、CPI 百分比量纲不同，叠加会误导），需要同看时用表格并列或分图。
