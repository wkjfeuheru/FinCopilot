# 盈利能力：指标体系、杜邦归因与质量核查

> 工具联动：`get_financials`（三表）、`get_indicators`（指标）、`calc_metrics(method="dupont")`
> （杜邦分解，数据已在会话中时传 `cids` 复用）、`get_peers`（同业对照）、
> `get_announcements`（关联交易/减值公告）、`make_chart`（盈利/杜邦趋势或同业对比图）。
> 分解**必须用工具计算**，不要手工算。

## 一、核心指标

| 指标 | 公式 | 含义 | 标准参考 |
|---|---|---|---|
| 毛利率 | (营收−营业成本)/营收 | 定价能力与成本控制 | 消费 30–60%／硬件 20–40%／软件 50–80% |
| 净利率 | 净利润/营收 | 最终盈利能力 | 优秀 >15%／一般 5–15% |
| ROE | 净利润/平均净资产 | 股东资本回报 | 优秀 >20%／良好 15–20% |
| ROA | 净利润/平均总资产 | 资产使用效率（剔杠杆） | 轻资产 >10%／重资产 3–8% |

分析要点：纵向看趋势（3–5 年），横向比同业（`get_peers`）；毛利率−净利率差值反映费用管控；
ROE 与 ROA 的差反映杠杆水平。

## 二、杜邦分解（ROE 归因）

三因素：`ROE = 净利率 × 总资产周转率 × 权益乘数`
五因素：进一步拆出税负率、息税前利润率、利息负担率。

**步骤**：
1. `calc_metrics(method="dupont", symbol=...)` 取分解表；数据已在会话中则传 `cids`。
2. **纵向**：与自身近 3–5 年比，判断哪个因子在变。
3. **横向**：与同业比，判断行业共性还是公司特性。
4. **只对变化最大的那个因子下结论**——三项都谈等于没说。

**解读话术**：
- 净利率驱动：品牌/技术壁垒型。追问毛利率与费用率走向，判断壁垒是否削弱。
- 周转率驱动：零售/制造型。盯存货与应收周转天数是否恶化（联动 efficiency.md）。
- 权益乘数驱动：**风险信号**。确认负债结构与利息保障倍数；高 ROE 来自加杠杆要打折（联动 health.md）。

| 现象 | 常见解释 | 需进一步验证 |
|---|---|---|
| 净利率升、周转降 | 提价/结构升级，或渠道压货 | 存货与应收增速是否超营收 |
| 净利率降、周转升 | 降价换量 | 毛利率与销量是否同向 |
| 权益乘数升 | 加杠杆扩产或补流 | 有息负债与利息保障倍数 |

**口径注意**：半年度 ROE 未年化，不可与全年直接比较。

**配图**（增强解读，非必需）：ROE 或杜邦三因子近 3–5 年趋势 → `make_chart(type="line", ...)`
折线（多因子同图可用 `series`）；同业毛利率/净利率横向对比 → 分组柱。趋势已用表格列清时不重复配图。

## 三、盈利质量与造假核查

对每一项给出**结论 + 依据数字 + cid**；数据不足时明确写"数据不足，无法判断"。

**核查清单（≥6 项逐项过）**：
1. **经营现金流/净利润**：长期 <1 利润未变现（最重要）；连续 3 年 <1 需警惕。
2. **应收增速 vs 营收增速**：持续快于营收 → 放宽信用换收入，回款质量下降。
3. **存货周转天数**：持续上升 → 滞销或备货过度，可能减值（结合行业旺季判断）。
4. **非经常性损益占比**：占比高 → 变卖资产/补助/投资收益，不可持续；用扣非增速复算。
5. **毛利率异常**：显著高于同业且无品牌/技术解释 → 核实收入确认口径。
6. **其他应收款/关联交易**：占比高 → 资金占用/收入独立性存疑；查 `get_announcements` 关联交易公告。
7. **费用率与利润增速背离**（可选）：利润增速远超营收而费用率未降 → 核实增长来源。

**红旗信号**（来自造假识别框架）：营收增长与现金流背离、异常高毛利、频繁商誉减值、
关联交易占比高、频繁更换审计机构。

**验证方法**：交叉验证（收入与纳税/用电量/运费匹配）、纵向对比（历史异常波动）、
横向对比（同业）、现金流验证（利润与现金匹配度）。

**总评口径**：

| 结论 | 判定 |
|---|---|
| 健康 | 无明显异常，经营现金流/净利润 ≥ 1 |
| 需关注 | 1–2 项偏离但可用业务原因解释 |
| 存疑 | ≥3 项异常，或现金流/净利润连续多年 <1 |

**纪律**：异常项只陈述事实与可能解释，**不指控造假**；异常项转入报告风险提示章节。
