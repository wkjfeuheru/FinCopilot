# 个股深度研究报告模板

> 用途：用户明确要求个股研报成稿时，按本模板组织 `write_report` 的 topic/core_view/sections/risks。
> 前提：各章素材已在会话中完成（含 cids）；缺素材先补分析，不编造。

## 章节结构

1. **核心观点**（3–5 条）
   - 每条一句话结论 + 关键数字，**每条必须带 {cite:cid}**。
2. **公司摘要**
   - 主营业务、行业地位、商业模式要点（来自取数与公开资料，标注来源）。
3. **财务摘要**
   - 关键指标表：营收、净利润、ROE、毛利率、负债率（标注报告期，带 citation）。
   - 杜邦归因结论：哪一因子主导 ROE 变化（只谈变化最大的因子）。
   - **建议配图**：ROE 或杜邦因子多期趋势 → 折线。
4. **盈利质量**（若做过质量核查）
   - 逐项结论 + 总评（健康/需关注/存疑）；异常项转入第 7 章风险。
5. **估值分析**（按标的特性二选一或互证）
   - 现金流稳定 → DCF：假设表（WACC 分量、三情景 g）+ 敏感性矩阵。
   - 周期/轻资产 → 可比：可比组表（中位数、目标分位）+ 修正说明。
   - **建议配图**：自身估值历史分位 → 折线；同业 PE/PB/ROE 对比 → 分组柱。
   - 表述为"在 X 假设下估值区间为 Y"，**不下买卖建议**。
6. **成长性判断**（若为成长类标的）
   - 增速拆解、可持续性证据（份额/订单/结构）。
7. **风险提示**（≥5 条，每条 = 风险 + 触发条件 + 观测指标）
   - 候选来源：质量核查异常项、高估值分位、行业政策、公司治理（质押/关联交易）。
8. **附录**
   - 数据来源由 write_report 管道自动生成（citation 全量 + 免责声明），不手写。

## 写作纪律（成稿必守）

- 每个结论性数字带 {cite:cid}；无来源数字会被管道标 [!无来源:n]，回头补数而不是删标记。
- 比例用百分号；比例之差写"高/低 X 个百分点"，不用 pct/pp。
- 正文不出现工具名与系统内部细节；溯源交给引用编号与附录。
- 图表先 `make_chart` 生成再引用路径；单位与口径（TTM/静态、复权方式）随数字标注。
  配图按内容判断（趋势→折线、对比→分组柱），不为配图而配图。
- 不下买卖建议、不给目标价；素材不足时缩短报告并写明缺什么。
