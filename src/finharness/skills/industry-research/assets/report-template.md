# 行业研究报告模板

> 用途：用户明确要求行业研报成稿时使用。前提同个股模板：素材先齐、cids 先有。

## 章节结构

1. **核心观点**（3–5 条）
   - 每条一句话结论 + 关键判断（生命周期阶段/格局/景气位置），**每条带 {cite:cid}**。
2. **行业概览**
   - 行业定义与边界口径、产业链图谱（上中下游一句话各是什么）、当前规模与增速。
3. **生命周期判断**
   - 当前所处阶段 + 依据链（增速 vs GDP、渗透率、集中度趋势）；与可比行业对标。
4. **竞争格局**
   - 市场结构类型、集中度（CR3/CR5）及趋势、主要参与者对比、竞争维度与壁垒。
   - **建议配图**：主要参与者份额/CR5 对比 → 分组柱。
5. **景气度跟踪**
   - 量/价/利三类信号各自的状态与数据日期；库存/产能周期定位（如适用）。
   - **建议配图**：行业指数或单个景气指标的历史趋势 → 折线（图注写明指标与日期）。
6. **行业空间测算**
   - 测算方法（TAM/渗透率/量价）、口径与基准年、假设各自标注来源；给区间不给点值。
7. **投资逻辑**
   - 关键成功因素 → 行业层面的条件性判断（"若 CR5 继续…则…"）；涉及代表公司时
   - 只陈述"在 X 要素上有优势的证据"，不推荐标的。
8. **风险提示**（≥5 条，每条 = 风险 + 触发条件 + 观测指标）
   - 来源：行业特有风险（政策/周期/技术替代/上游价格）+ 系统性风险。
9. **附录**
   - 数据来源由管道自动生成，不手写。

## 写作纪律（成稿必守）

- 行业判断落到数据（集中度、ROE 中位数、价格趋势），无数据支撑的定性判断要注明推断依据。
- 三层结论（结构/格局/景气）互相印证；矛盾处显式指出，不回避。
- 空间与景气分开表述：空间大≠当下景气好。
- 数字带 {cite:cid}；正文不出现工具名；不下买卖建议。
- 配图按内容判断：趋势→折线、横向对比→分组柱；单点读数或已说清的表格不配图。
  图表先 `make_chart` 生成再引用路径，图注写明口径与数据日期。
- 公开检索数据（渗透率、行业规模）标注来源机构与年份。
