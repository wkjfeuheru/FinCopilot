# 景气度分析：跟踪指标体系与周期定位

> 工具联动：`get_industry_perf`（申万行业指数行情，反映行业量价；省略行业名返回一级行业总览）、
> `get_peers`（行业内公司营收/利润增速聚合，作行业景气近似）、
> `get_valuation`（行业估值中枢与市场预期）、`get_market_news` / `web_search`
> （价格、订单、政策等先行信号）、`make_chart`（景气指标趋势/对比图）。

## 一、跟踪指标体系

给出**可跟踪、可获取**的指标，而非模糊的"关注需求"：

| 类别 | 指标 | 来源 |
|---|---|---|
| 量 | 产销量、开工率、库存水平 | 行业协会/统计公报（`web_search`） |
| 价 | 产品价格、价差（煤价、钢价、白酒批价等） | 公开行情/行业网站 |
| 利 | 行业毛利率、单位盈利 | `get_peers` 聚合同业财务 |
| 资本市场 | 行业估值中枢、龙头盈利预测调整 | `get_valuation` / `get_market_news` |
| 先行信号 | 订单、招标、政策发文、行业新闻 | `get_market_news` |

## 二、周期定位

- **库存周期**：主动补库→被动补库→主动去库→被动去库；量价组合是判断依据
  （量价齐升=补库，量跌价升=被动去库等）。
- **产能周期**：在建工程/资本开支领先产能释放 2–3 年；产能投放集中期往往对应价格低点。
- 与行业生命周期区分：景气度是**当下波动**，生命周期是**长期位置**（见 lifecycle.md）。

## 三、判读纪律

- 景气判断要**分信号类型下结论**：量的信号、价的信号、利的信号分别说，且注明各自
  数据日期；信号打架时要指出（量升价跌=复苏早期或过剩晚期，需其他证据裁决）。
- 高频价格数据（批价/现货价）注意时效，标注取数日期。
- 景气度是**时点判断**，结论写成"当前处于 X 阶段的依据是…"，不外推为长期判断。
- 库存/产能周期的阶段判断给出可证伪的观察条件（"若 X 指标继续上行则…"）。

**配图**（增强解读，非必需）：行业指数或**单个**景气指标的历史趋势 → `make_chart(type="line",
cids=[行业行情cid])` 折线，图注写明指标名与取数日期；多行业同指标对比 → 分别取数后各画一图
或表格并列（不同行业量纲可比时才叠加）。单期读数不配图。
