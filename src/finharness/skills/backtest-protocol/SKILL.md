# 回测规范

> 注：`run_backtest` 工具尚未实现；本技能当前用于统一回测口径与判读方法，工具就绪后直接复用。

## 样本内外划分

- **先划分，再优化**：把区间分成样本内（In-Sample，约 70%）与样本外（Out-of-Sample，约 30%），**严禁用样本外数据调参**。
- 参数只在样本内寻优；样本外只做一次验证，不反复试。
- 若必须滚动验证，用**滚动窗口**（walk-forward）：逐段向前，每段用历史调参、用紧邻的未来验证。
- 时间序列**不可随机切分**（会引入未来信息），必须按时间顺序切。

## 过拟合检查

| 检查项 | 判据 | 红灯信号 |
|---|---|---|
| 样本内外差异 | 样本外绩效不应大幅劣于样本内 | 样本外收益转负或夏普腰斩 |
| 参数敏感性 | 邻近参数应给出相近结果 | 参数微调即绩效剧变（孤岛最优） |
| 交易次数 | 样本量要足够 | 交易 < 30 次，统计意义弱 |
| 复杂度 | 参数越少越稳 | 规则复杂、参数众多 |
| 基准对比 | 必须跑买入持有基准 | 跑不赢买入持有则无价值 |

## 绩效指标口径

| 指标 | 口径 |
|---|---|
| 年化收益 | 按几何年化，注明是否含交易成本 |
| 夏普比率 | (年化收益 − 无风险利率) / 年化波动率；注明无风险利率取值 |
| 最大回撤 | 峰谷最大跌幅，注明发生区间 |
| 卡玛比率 | 年化收益 / 最大回撤 |
| 胜率与盈亏比 | 分别给出，二者需结合看 |

**必须说明**：是否计入交易成本与滑点、是否复权、无风险利率取值。三者不同会让结论不可比。

## 判读纪律

- 先给**样本外**结果，再给样本内——顺序颠倒会误导。
- 明确写出"该策略在 X 区间样本外表现为 Y"，不推广到未来。
- 跑不赢买入持有、或样本外失效时，**如实说明策略无效**，不要为参数找理由。
- 附净值曲线图（`make_chart`），并在图注写明区间与参数。
