# 量化因子研究报告模板

> 用途：用户明确要求因子/回测研究成稿时使用。前提：回测已由 `run_backtest` 实际执行；
> **无回测数据不写数字**。

## 章节结构

1. **核心观点**（2–4 条）
   - 因子是否有效、样本外表现、主要局限，**每条带 {cite:cid}**。
2. **因子假设与构造**
   - 经济含义假设（为何该有预测力）→ 因子表达式 → 预处理（去极值/标准化/中性化）。
3. **回测设计**
   - 数据：标的/股票池、区间、复权口径。
   - 参数：样本划分（is_ratio）、调仓周期、成本假设（cost_bps/slippage_bps）、
     无风险利率取值。
   - 基准：买入持有（单股）/ 等权组合（横截面）。
4. **回测结果**（**样本外在前**）
   - 单股序列：绩效表（年化/夏普/最大回撤/卡玛/胜率/盈亏比）+ 净值曲线图
     （`make_chart(cids=[回测cid], type="line", series=["nav","benchmark_nav"])`，策略与基准同图；
     图注写明区间与参数）。
   - 横截面：IC 时序与统计（均值/ICIR/胜率）+ 分组净值叠加折线
     （`series=["group_1_nav",...,"group_N_nav"]`）+ 多空组合表现。
5. **过拟合检查与判读**
   - 样本内外对比（是否腰斩/转负）、参数敏感性（±20% 调参）、交易次数、
     孤岛最优排查；结论如实（无效就说无效）。
6. **试验披露**
   - 本次共试验 N 个候选（上限 50）；相关性去重说明（>0.8 视为同一因子）。
7. **风险提示**（≥3 条）
   - 候选：生存者偏差（横截面）、口径变更、区间依赖、过拟合残余风险；
   - 每条含触发条件（何种市场环境下因子可能失效）与观测指标。
8. **附录**
   - 数据来源由管道自动生成，不手写。

## 写作纪律（成稿必守）

- **无回测数据不写数字**：未实际执行的回测不得出现在报告中。
- 结论限定"在 X 区间样本外表现为 Y"，不外推未来、不下买卖建议；
  多空组合是因子有效性描述，不是可交易产品。
- 成本/复权/无风险利率三口径必须披露，否则结果不可比。
- 净值曲线图注写明区间与参数；数字带 {cite:cid}；正文不出现工具名。
