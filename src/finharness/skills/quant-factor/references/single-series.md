# 单股序列：时序因子构造与判读

> 工具联动：`get_kline`（OHLCV 日线，复权口径要注明）、`get_indicators`（财务字段，
> 如估值/换手）、`run_backtest`（单标的择时回测；返回净值帧已落盘可被引用）、
> `make_chart`（净值曲线；策略与基准用 `series=["nav","benchmark_nav"]` 同图）。

## 一、典型时序因子构造

| 家族 | 构造思路 | 示例 |
|---|---|---|
| 动量 | 过去 N 期收益的持续性 | `close/ts_delay(close,120)-1` |
| 反转 | 短期超跌/超涨的回补 | `-1*(close/ts_delay(close,5)-1)` |
| 波动率 | 低波动异象 | `ts_std(close/ts_delay(close,1)-1,20)` |
| 量价 | 量能确认价格趋势 | `ts_corr(close,volume,20)` |
| 流动性 | 换手/成交额水平 | `ts_mean(amount,20)` |

每个因子先写**经济含义假设**（为什么该有预测力），再写表达式。

## 二、回测执行（择时框架）

1. 因子值序列 → 信号映射（如因子值 > 0 持有，否则空仓；或分位数阈值）。
2. `run_backtest`：样本内 70% 寻优（`is_ratio=0.7`），样本外一次性验证；
   设定 `cost_bps`/`slippage_bps` 并在结论中披露。
3. 与**买入持有基准**对比：超额、夏普、回撤同时看。

## 三、判读口径（绩效表）

| 指标 | 口径 |
|---|---|
| 年化收益 | 几何年化，注明是否含交易成本 |
| 夏普比率 | (年化收益 − 无风险利率)/年化波动率，注明无风险利率取值 |
| 最大回撤 | 峰谷最大跌幅，注明发生区间 |
| 卡玛比率 | 年化收益/最大回撤 |
| 胜率与盈亏比 | 分别给出，结合看 |

**判读要点**：
- 先样本外后样本内；样本外夏普腰斩或收益转负 = 过拟合红灯。
- 交易次数 <30 的结论统计意义弱，要说明。
- 参数敏感性：±20% 调参看结果是否剧变（孤岛最优=过拟合信号）。
- 净值曲线用 `make_chart`：`run_backtest` 的净值帧已随 citation 落盘，直接
  `make_chart(type="line", cids=[回测cid], series=["nav","benchmark_nav"])` 把策略与买入持有
  基准同图对比，**勿重取数**；图注写明区间、参数与是否含成本。

## 四、纪律

- 复权口径（前复权/后复权）必须注明，不同口径的收益序列不可混用。
- 单标的结论不外推到其他标的；时序规律可能只是该标的特定阶段的结构。
- 明确写出"该策略在 X 区间样本外表现为 Y"，不推广到未来。
