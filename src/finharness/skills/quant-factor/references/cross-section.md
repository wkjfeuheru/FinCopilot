# 横截面：分组、IC 与多空判读

> 工具联动：`get_industry_perf` / `get_industry_constituents`（申万行业行情与成分股）或
> 指数成分（`get_industry_constituents` 同类路由，沪深300/中证500/中证1000）与显式 symbol 列表、
> `get_kline`（面板数据构建，按需拉取+缓存，股票数上限默认 300）、`run_backtest`
> （分组回测与 IC 计算；返回分组净值帧已落盘）、`make_chart`（分组净值叠加折线）。

## 一、适用前提

横截面因子 = **同一时点、跨股票**的可比量。面板 = N 只股票 × T 天的宽表。
股票池优先指数成分（沪深300/中证500/中证1000），或用户显式列表；全市场（~5000 只）
不做 v1 支持说明并说明原因。

## 二、研究流程

1. **假设**：经济含义（如"低波动股票被过度追捧后修正较慢"），先写假设再写表达式。
2. **构造**：因子表达式 + 横截面算子（`rank/zscore/quantile`——只在本方法论可用）。
   示例：`rank(ts_std(close/ts_delay(close,1)-1,20))`（低波动排名）；
   `rank(-pe_ttm)`（低市盈率）。估值变量为 `pe`/`pe_ttm`/`pb`/`pcf`/`总市值`，
   收益、分组与 IC 仍用收盘价。未知名字（如 ROE）会在取价前拒绝，换表达式，不要原样重试。
3. **预处理**：去极值（如 3σ/分位截断）、标准化（zscore）、中性化（可选，行业/市值）。
4. **检验**（两条腿，缺一不可）：
   - **IC 分析**：因子值与未来收益的秩相关（Spearman）时序 → IC 均值、ICIR（IC均值/IC标准差）、
     IC 胜率（IC>0 的期数占比）。
   - **分组回测**：按因子值分 N 组（默认 5），各组等权、按调仓周期（周/月）再平衡 →
     看组间收益**单调性**；多空组合 = Top 组 − Bottom 组。

## 三、判读口径

| 指标 | 判读参考 |
|---|---|
| IC 均值 | \|IC\|>0.03 具备一定预测力（月度口径常见 0.02–0.05） |
| ICIR | >0.5 因子稳定性较好 |
| IC 胜率 | >55% 方向一致率可接受 |
| 分组单调性 | Top→Bottom 组收益单调递减/递增为佳；仅首尾组有效而中间混乱则质量弱 |
| 多空组合 | 年化、夏普、回撤；与分组结论互相印证 |

**样本内外纪律**（沿用场景入口的回测纪律）：划分按时间切；因子构造与预处理参数只在
样本内定；样本外只验证一次。试验 ≤50 个/会话，相关性高的候选（横截面相关 >0.8）
视为同一因子去重。

## 四、纪律

- 面板构建的取数成本高：同股票同区间只拉一次（缓存复用），先小池验证再加规模。
- 生存者偏差要说明：股票池是**当前**成分，历史回测含前视（当前成分是未来信息），
  结论须注明此局限。
- 分组结论只证明因子在该池该区间有效，不外推到全市场。
- 不下买卖建议；多空组合是因子有效性描述，不是可交易产品。

**配图**（增强解读，非必需）：分组净值叠加折线 → `make_chart(type="line", cids=[回测cid],
series=["group_1_nav","group_5_nav"])`（多组可一次传多个 series，或只画首尾两组看分化）；
IC 时序可另配折线。图注写明股票池、调仓周期与分组数。
