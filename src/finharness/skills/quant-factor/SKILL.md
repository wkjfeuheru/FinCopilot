# 量化因子研究（场景入口）

> 本文件承载**回测纪律与工具调用约定**；判读口径在 `references/` 下按需加载。

## 场景界定

**进入本场景**：因子假设检验、回测校验、策略有效性判读——研究对象是"规律是否存在于数据"。

**不进入**：
- 单点行情/K 线查询（"600519 近一年走势"）→ 直接取数作答。
- 基本面分析（估值/盈利归因）→ `equity-research`。
- 逐标的对比 → `equity-research` 的多标的模式。

## 关注点确认

用户未指明研究类型时，先调用 `ask_user` 让用户选择——单股序列（时序择时验证）／横截面
（股票池内分组与 IC），并确认因子方向或策略、回测区间、股票池（横截面时）。用户已明确
（如"20 日均线回测茅台"）时**直接进入**，不再询问。

**因子研究必须先有经济含义假设**：用户未给出假设时，由你提出 1–2 个候选假设并说明依据，
经用户确认后再构造表达式，不从纯搜索开始。

## 回测纪律（两类方法论共用）

1. **样本内外划分**：按时间顺序切（**严禁随机切分**），样本内约 70%（`is_ratio` 默认 0.7）、
   样本外约 30%；参数只在样本内寻优，样本外只做一次验证，不反复试；
   需滚动验证时用 walk-forward（逐段向前，历史调参、紧邻未来验证）。
2. **基准**：必须跑买入持有基准；跑不赢基准的策略无价值。
3. **过拟合检查**（工具输出检查字段，你负责判读）：
   样本外大幅劣于样本内（收益转负/夏普腰斩=红灯）；参数敏感性（邻近参数应给出相近结果，
   微调即剧变=孤岛最优）；交易次数 <30 统计意义弱；参数越少越稳。
4. **试验上限**：同一会话内候选因子试验**≤50 个**；每个候选必须先附一句经济含义假设
   （为何该有预测力），无假设的纯搜索不试。
5. **成本与口径**：是否计入交易成本与滑点（`cost_bps`/`slippage_bps`）、是否复权、
   无风险利率取值——三者必须说明，否则结果不可比。
6. **判读顺序**：先给样本外结果，再给样本内——顺序颠倒会误导。
7. **诚实披露**：跑不赢基准或样本外失效时如实说明策略无效，不为参数找理由；
   结论必须披露"本次共试验 N 个因子"；相关性高的候选视为同一因子，不重复计数。

## 调用约定

**工具**：`run_backtest`（按需注入，直接调用即可）。策略/因子以**参数声明**，
不执行任意代码：单股用内建策略（`strategy=ma/momentum`）或时序因子表达式；
横截面用带 `rank/zscore/quantile` 的因子表达式 + 股票池（`pool` 可为指数名
沪深300/中证500/中证1000、申万行业名，或显式代码列表）。工具已内置样本内外切分、
成本/滑点、买入持有基准与过拟合检查字段。

| 研究类型 | 输入 | 加载 |
|---|---|---|
| 单股序列 | `symbol` + 时序因子表达式或内建策略（ma/momentum） | references/single-series.md |
| 横截面 | `pool`（指数成分股或显式列表，默认上限 300 只）+ 因子表达式 | references/cross-section.md |

**因子表达式**（白名单算子、AST 解析、绝不 eval）：时序 `ts_mean/ts_std/ts_sum/ts_min/
ts_max/ts_delay/ts_delta/ts_pct_change/ts_rank/ts_corr/ts_cov/ts_skew`，元素级 `abs/log/
sign/sqrt/exp/clip/where`，算术/逻辑 `+ - * /` 与比较/布尔；变量限 OHLCV/成交额/换手，
以及横截面估值序列 `pe`/`pe_ttm`/`pb`/`pcf`/`总市值`（财报字段如 ROE 不在回测面板中，
用了会在取价前被拒绝）；窗口 ≤250、表达式深度受限。横截面算子 `rank/zscore/quantile`
属横截面专用，单股序列不可用。低市盈率写成 `rank(-pe_ttm)`。**先写经济含义假设，再写表达式。**

## 输出契约

- **默认对话内作答**：绩效表（年化/夏普/最大回撤/卡玛/胜率/盈亏比）+ 样本内外对比 +
  过拟合判读 + 试验次数披露；数字带 `{cite:cid}`。
- **配图是回测的默认组成**（不必等用户点名）：单股回测**必配净值曲线**，策略与买入持有基准
  同图（`make_chart(cids=[回测cid], type="line", series=["nav","benchmark_nav"])`）；横截面回测配
  分组净值叠加（`series=["group_1_nav",...]`，可加 `long_short_nav`）；IC 时序可另配折线。
  净值图注写明区间、参数与是否含成本。回测帧已随 citations 落盘，直接按 cid 引用、勿重取数。
- **用户明确要求报告** → 读 `assets/report-template.md` → `make_chart` 按上述判据画图 →
  `write_report` 成稿（写入前确认，成稿后自动风控终审）。
- 因子结论限定"在 X 区间样本外表现为 Y"，不外推未来、不下买卖建议。
