# 杜邦分析（ROE 归因）

## 三因素分解

```
ROE = 销售净利率 × 总资产周转率 × 权益乘数
    = (净利润/营业收入) × (营业收入/总资产) × (总资产/股东权益)
```

## 五因素分解（进一步拆分）

```
ROE = 税负率 × 息税前利润率 × 资产周转率 × 权益乘数 × 利息负担率
```

## 归因步骤

1. 先用 `calc_metrics(method="dupont", symbol=...)` 取得分解表，**不要手工计算**。
   - 若数据已在会话中，传 `cids=[...]` 复用，避免重复取数。
2. **纵向**：与自身历史（近 3–5 年）对比，判断哪一因子在变化。
3. **横向**：与同业对比（`get_peers`，或对同一指标跑一次 `calc_metrics`），判断是行业共性还是公司特性。
4. **只对变化最大的那一个因子下结论**，不要面面俱到——三项都谈等于没说。

## 解读话术

- **净利率驱动型**：多见于品牌/技术壁垒企业。需追问毛利率与费用率走向，判断壁垒是否在削弱。
- **周转率驱动型**：多见于零售/制造。需关注存货周转天数与应收账款周转天数是否恶化。
- **权益乘数驱动型**：**风险信号**。需确认负债结构与利息保障倍数；高 ROE 若来自加杠杆，质量要打折。

## 判定参考

| 现象 | 常见解释 | 需进一步验证 |
|---|---|---|
| 净利率升、周转降 | 提价或结构升级，也可能是渠道压货 | 存货与应收增速是否超营收 |
| 净利率降、周转升 | 降价换量 | 毛利率与销量是否同向 |
| 权益乘数升 | 加杠杆扩产或补流 | 有息负债与利息保障倍数 |

## 注意

- **半年度 ROE 不可与全年直接比较**（未年化）。比较前先统一口径，或只用年末数。
- 分解结果必须带 citation（cids）回溯到原始数据；无来源的数字不得写入结论。
