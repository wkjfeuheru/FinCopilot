# 杜邦分析（ROE 归因）

## 三因素分解

```
ROE = 销售净利率 × 总资产周转率 × 权益乘数
    = (净利润/营业收入) × (营业收入/总资产) × (总资产/股东权益)
```

## 五因素分解（进一步拆分）

```
ROE = 税负率 × 息税前利润率 × 资产周转率 × 权益乘数 × 利息负担率
```

## 归因步骤

1. 先用 `calc_metrics(method="dupont", symbol=...)` 取得分解表，避免手工计算。
2. 与自身历史（近 3-5 年）对比，判断哪一因子在变。
3. 与同业（`get_peers`）对比，判断是行业共性还是公司特性。
4. 只对**变化最大**的因子下结论，不要面面俱到。

## 解读话术

- 净利率驱动型：常见于品牌/技术壁垒企业，需追问毛利率与费用率的走向。
- 周转率驱动型：常见于零售/制造，需关注存货与应收周转天数。
- 权益乘数驱动型：**风险信号**，需确认负债结构与利息保障倍数。

## 注意

- 半年度 ROE 不可与全年直接比较（未年化），比较前先统一口径。
- 分解结果必须带 citation（cids）回溯到原始数据。
