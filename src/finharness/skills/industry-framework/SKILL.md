# 行业分析三层框架

自上而下三层：先看**结构**（五力），再看**结果**（格局），最后看**当下**（景气）。三层结论要能互相印证。

## 第一层：波特五力（判断行业结构性盈利水平）

| 力 | 关键问题 | 判断依据 |
|---|---|---|
| 现有竞争 | 竞争者数量与同质化程度 | 价格战频率、行业集中度 CR5 |
| 新进入者威胁 | 进入壁垒高低 | 牌照、资本开支、技术、渠道门槛 |
| 替代品威胁 | 替代技术或模式 | 替代品的性价比趋势 |
| 供应商议价力 | 上游集中度 | 关键原料是否被少数厂商控制 |
| 客户议价力 | 下游集中度 | 大客户占比、比价能力 |

- 五力越弱 → 行业长期 ROE 越高。用 `get_peers` 的可比公司 ROE 中位数交叉验证这一判断。

## 第二层：竞争格局（判断谁能赢）

1. **集中度**：CR5/CR10 及其趋势（提升=强者恒强，分散=混战）。
2. **差异化维度**：品牌 / 成本 / 技术 / 渠道，识别主要竞争维度。
3. **公司位置**：目标标的是龙头、追赶者还是边缘者；份额是否在提升。
4. **格局阶段**：导入期 → 成长期 → 成熟期 → 出清期，不同阶段估值逻辑不同。

## 第三层：景气跟踪指标（判断当下时点）

给出**可跟踪、可获取**的指标，而非模糊的"关注需求"：

- **量**：产销量、开工率、库存水平
- **价**：产品价格、价差（如煤价、钢价、白酒批价）
- **利**：行业毛利率、单位盈利
- **先行信号**：订单、招标、政策发文、行业新闻（`get_market_news`）

输出为 `{list:industry_map}`，每层 3–5 条要点。

## 纪律

- 三层结论必须互相一致；若"五力很弱"但"格局分散且公司份额下滑"，需指出这个矛盾。
- 行业判断要落到数据（集中度、ROE 中位数、价格趋势），不能只做定性描述。
- 涉及不确定判断时给出条件："若 CR5 继续提升，则龙头溢价有望维持"。
- 不做买卖建议；数据带 citation。
