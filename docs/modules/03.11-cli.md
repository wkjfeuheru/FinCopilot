### 3.11 cli.py —— 进程入口与 REPL（CLI 形态）

**职责**：进程入口、依赖组装（composition root）、命令分派（repl/report/serve）、REPL 渲染与命令路由、非交互模式。

**3.11.1 入口与参数**

```
fin [--provider kimi|glm|deepseek] [--mode default|plan|auto] [--no-color]
fin report -p "研究需求" [--mode auto] [--topic 文件名主题] [-o output目录]
fin serve [--host 127.0.0.1] [--port 8000] [--mode default|plan|auto] [--reload]
fin --version
```

- `cli.main()` 流程：加载 Settings → 校验 → 组装 SessionDeps（cache/cite/gate/hooks/registry/context/loop）→ 按 argv 分派 run_repl() / run_report() / run_serve()（§3.12）。
- 首次运行建目录（data_cache/output/logs/skills），缺依赖给出可执行修复命令。

**3.11.2 REPL（run_repl）**

- 提示符 `❯ `；rich 渲染流式正文（Live 增量）、工具状态行（`✓ get_indicators(600519) 1.4s`、计划步骤 ✓/✗/↻）。
- 命令表（以 `/` 开头，不进入 LLM）：

| 命令 | 行为 | 权限/备注 |
|---|---|---|
| `/plan on\|off` | 切换复杂问题是否先 research_plan | 会话级 |
| `/skills` | list_skills 渲染 | 只读 |
| `/tools` | 已注册工具清单（resident/lazy 标记） | 只读 |
| `/citations [symbol]` | cite.to_appendix_md 分页 | 只读 |
| `/cache` | 缓存命中统计 | 只读 |
| `/cost` | 会话用量与成本 | 只读 |
| `/memory` | 读 memory.db 渲染 L3 记忆（最新结论/标的池/约定），并展示 MEMORY.md 视图 | 只读 |
| `/audit tail -n 20` | 审计尾部 | 只读 |
| `/model` | 当前厂商/模型/价格 | 只读 |
| `/compact` | 手动触发压缩 | 只读 |
| `/clear` | 清屏（不丢上下文） | — |
| `/report [主题]` | 把当前 ResearchContext → ReportPipeline | write（确认） |
| `/quit` / Ctrl+D | 退出：L2 蒸馏提交 L3（memory.db）+ 渲染 MEMORY.md + audit session_end | — |

- 异常处理：Provider Auth/网络错误 → 红色提示"密钥/网络"并保持会话；工具级错误 → 已回填不打扰；KeyboardInterrupt → 中断当前 turn 返回提示符（不丢上下文）。
- **退出时**：flush audit 缓冲、L2 蒸馏提交 L3（conclusions/symbols UPSERT → 渲染 MEMORY.md 视图）、打印成本汇总。

**3.11.3 研报模式（run_report，非交互）**

- `fin report -p "..."`：起一次带固定 system prompt（含四场景技能路由与输出约束）的 AgentLoop，模型自行：取数 → calc → make_chart → write_report（内部触发 ReportPipeline，并在成稿后自动跑风险终审，见 §3.10）。
- write 确认策略：交互 TTY 且非 auto → 确认；非 TTY 非 auto → 拒绝并提示 `--mode auto`；auto → 放行。
- 结束时打印：产物路径、citation 条数、图表数、token/成本（含分 Agent 维度）、audit 条目数——Demo B 验收画面即来自这里。
