### 3.10 coordinator/ —— 多智能体（阶段二，演示级）

**职责**：主 Agent 派生子任务上下文，回收结论摘要；不改变 AgentLoop 本身。

```python
class Coordinator:
    def __init__(self, deps: SessionDeps): ...   # 复用 provider/cache/cite/settings
    async def spawn_agent(self, *, task: str, focus: str) -> SubAgentResult:
        # 新建独立 ResearchContext + 消息缓冲（同进程、隔离上下文）
        # 子 Agent 限定工具子集（macro→web_search/news；risk→只读文件+checklist 语义）
        # 只回传：结论摘要 + 其产生的 citations（并入主会话注册表，cid 连续）
```

- **风险终审 Agent**：`focus=risk`，加载 `risk-checklist` skill，对已渲染研报 Markdown 做检查，输出风险修改意见列表，主 Agent 决定是否修订——演示点：`fin report --with-risk`。
- 成本叠加：子 Agent usage 独立记账，计入 `/cost` 汇总（分 Agent 维度展示）。
- `spawn_agent` 由模型经工具触发（v1.1 §3.9），工具权限 read；实现放在 M5，进度紧可跳过（不影响主线验收）。
