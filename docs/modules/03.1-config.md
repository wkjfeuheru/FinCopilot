### 3.1 config/ —— 配置中心

**职责**：集中管理全部配置，唯一真实来源为仓库根目录 `settings.json` + 环境变量覆盖；加载期和启动期各校验一次。

```jsonc
// 根目录 settings.json 示例（键与 Pydantic 字段一一对应）
{
  "model": {
    "provider": "deepseek",          // 首选厂商
    "model_name": "deepseek-chat",
    "temperature": 0.1,
    "max_tokens": 4096,
    "thinking": { "enabled": true, "budget_tokens": 2048 }   // 支持厂商开关
  },
  "providers": {                     // 厂商表：anthropic 兼容 or openai 兼容
    "kimi":    { "kind": "anthropic_compat", "base_url": "https://api.moonshot.cn/anthropic/v1", "env_key": "MOONSHOT_API_KEY", "cost_per_1m": {"input": 2.0, "output": 12.0} },
    "glm":     { "kind": "anthropic_compat", "base_url": "https://open.bigmodel.cn/api/anthropic/v1", "env_key": "ZHIPU_API_KEY",  "cost_per_1m": {"input": 1.0, "output": 4.0} },
    "deepseek":{ "kind": "openai_compat",    "base_url": "https://api.deepseek.com/v1",            "env_key": "DEEPSEEK_API_KEY", "cost_per_1m": {"input": 1.0, "output": 2.0} },
    "fake":    { "kind": "fake" }
  },
  "permission": { "default_mode": "default" },   // default | plan | auto
  "tools": {
    "timeout_default_s": 30,         // 数据接口默认超时
    "timeout_overrides": { "run_backtest": 300, "read_pdf": 60 },
    "resident": [/* 20 个工具名，见 §3.4.1 表；留空则用内置默认 */],
    "lazy":     [/* 4 个工具名 */]
  },
  "data": {
    "adapter_order": ["akshare", "tushare","baostock"],
    "tushare_token_env": "TUSHARE_TOKEN",
    "throttle_seconds": 1.0,         // akshare 请求节流
    "cache_dir": "data_cache",
    "cache_ttl_days": { "quote": 1, "kline": 1, "indicators": 7, "financials": 365, "announcements": 7 }
  },
  "context": {
    "max_turns": 30, "compaction_ratio": 0.8, "trim_rows": 20,
    "max_result_tokens": 1000, "max_tool_schema_tokens": 60,
    "short_mem_cap": 200,             // L2 事件环上限（§3.6.4）
    "recall_max_tokens": 400,         // L2 追问召回注入上限
    "ltm_inject_max_tokens": 600      // L3 启动注入上限（历史结论区）
  },
  "audit": { "log_path": "logs/audit.jsonl" },
  "server": {                             // v1.1：HTTP/SSE 服务层
    "host": "127.0.0.1", "port": 8000,
    "session_ttl_s": 1800,                // 会话 idle 回收
    "confirm_ttl_s": 120,                 // write 确认等待上限
    "static_dir": "src/finharness/server/static",
    "allow_remote": false                 // true 才允许 0.0.0.0（须配 TLS 反代）
  },
  "paths": { "output_dir": "output", "memory_db": "data_cache/memory.db", "skills_dir": "skills" }
}
```

- 实现：`pydantic-settings` 的 `Settings(BaseSettings)` 与冻结嵌套模型；全部字段采用严格类型，未知 JSON 字段、非法枚举和越界值均拒绝。深合并优先级为：环境变量 > `settings.json` > 代码内置默认。
- 默认 Provider：`deepseek`（`deepseek-chat`）；内置表包含 `deepseek`、`kimi`、`glm`、`fake`。`fake` 只允许显式选择，不作为错误降级目标。
- 路径：`data.cache_dir`、`audit.log_path`、`server.static_dir` 和 `paths.*` 的相对值均以 `settings.json` 所在目录为基准解析为绝对路径。加载配置不会创建目录。
- 加载期校验：检查 JSON 结构、字段类型、Provider 端点、引用关系、数值范围和远程监听安全规则。`allow_remote=false` 时只允许 `127.0.0.1`、`::1` 或 `localhost`；远程监听只允许 `permission.default_mode=default`。
- 启动期校验：`Settings.validate_runtime()` 检查所选 Provider 的 API Key 和审计日志父目录可写性，但不访问网络、不创建目录。缺少 Key 时明确失败，不自动切换 Provider。
- 运行期只读：`Settings` 及每个嵌套配置模型均为 frozen，集合字段也转换为不可变容器；修改配置需要重启进程。

#### 环境变量契约

仅支持 `FINH_` 前缀和单下划线字段路径。双下划线或未知的 `FINH_` 变量会被拒绝，避免拼写错误被静默忽略。字符串直接填写；整数、浮点数和布尔值使用 JSON 标量；列表、对象必须使用 JSON。

常用示例：

```powershell
$env:FINH_MODEL_PROVIDER = "glm"
$env:FINH_MODEL_MODEL_NAME = "glm-4.5"
$env:FINH_MODEL_THINKING_ENABLED = "false"
$env:FINH_SERVER_PORT = "8123"
$env:FINH_DATA_ADAPTER_ORDER = '["akshare"]'
$env:FINH_TOOLS_TIMEOUT_OVERRIDES = '{"get_kline":45}'
```

支持覆盖的分组如下：

- `MODEL_*`：`PROVIDER`、`MODEL_NAME`、`TEMPERATURE`、`MAX_TOKENS`、`THINKING_ENABLED`、`THINKING_BUDGET_TOKENS`。
- `PROVIDERS`：用一个 JSON object 整体替换 Provider 表；内置 Provider 还可使用 `PROVIDERS_<DEEPSEEK|KIMI|GLM|FAKE>_<字段>` 覆盖，其中成本字段为 `COST_PER_1M_INPUT` 和 `COST_PER_1M_OUTPUT`。
- `PERMISSION_*`：`DEFAULT_MODE`。
- `TOOLS_*`：`TIMEOUT_DEFAULT_S`、`TIMEOUT_OVERRIDES`、`RESIDENT`、`LAZY`。
- `DATA_*`：`ADAPTER_ORDER`、`TUSHARE_TOKEN_ENV`、`THROTTLE_SECONDS`、`CACHE_DIR`、`CACHE_TTL_DAYS`。
- `CONTEXT_*`：与本节 JSON 示例中的 context 字段一一对应。
- `AUDIT_LOG_PATH`、`SERVER_*` 与 `PATHS_*`：与本节 JSON 示例中的对应字段一一对应。

Provider 的 API Key 本身不使用 `FINH_` 前缀；配置中的 `env_key` 只保存变量名，真实密钥仍由 `DEEPSEEK_API_KEY`、`MOONSHOT_API_KEY`、`ZHIPU_API_KEY` 或自定义变量提供。
